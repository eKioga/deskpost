# Codex parity record (first draft)

This first draft compares reader-visible Deskpost behavior in Claude Code and Codex against the approved `deskpost-desk` Codex parity plan. Status means **same** (the same result), **close** (a visible difference), or **not possible yet** (no working Codex route has been proved). A registration alone does not establish a real-session effect.

## Hook and tool surface inventory

A hook matcher runs only for names it matches. Hooks are best effort: if one is untrusted, disabled, errors or times out, a direct file read may proceed. ## The Desk pane (deskpost dashboard --watch)

The Desk pane is a short, three-line Desk strip with an optional save/closeout line, intended under Codex across the tab's full width in Orca: always shown and refreshed on its own, never only in chat. The seat launcher requests it automatically for Codex (or Claude with `--pane on`), immediately after retitling the agent tab. `deskpost dashboard` reads once; `deskpost dashboard --watch --seat <name>` keeps the pane current. Orca saves the split layout with the worktree. The dashboard command itself is read-only; the seat launcher owns the split request.

Watch requires an explicit `--seat <name>`. Without it, it refuses before reading: `deskpost dashboard --watch needs --seat <name>: the pane never chooses a seat.` Watch never reads a binding or `LIBRARY_SEAT`, claims, binds or starts a seat. A Desk belongs to a seat, and there is no default seat. One-shot use without `--seat` resolves the seat as `deskpost desk` does. Both forms show the `deskpost desk --seat <name>` overview and its exact conversation checkpoint, when present. A seat that cannot be read is said plainly in the pane, using the refusal's own words; after a failed refresh, the last good frame stays with an `unknown since` age and the refusal's first line.

Line 1 shows a held dot, the seat and `held` (or `seat not held`), then this seat's Letters, Reports and Holding counts, each positive count with its oldest pending age in parentheses. Four spaces separate items, with `as of ` and an eight-cell local clock field right-aligned at the edge. Line 2 starts `Books  `, lists audit-due Books first with ` (audit due)`, and separates whole names by two spaces. Line 3 starts `Hubs   ` and lists Hub names without their leading `projects/`. Missing counts show `?`; unknown dates show `unknown`. Save, closeout and upkeep are omitted entirely until a record the pane can read exists; they are never inferred.

Fit by content: first reduce line 1's gaps from four spaces to two, then omit the clock, then use the stacked form. The strip never shortens or drops the seat, inbox counts or their ages. Books and Hubs always keep whole names and count omitted names as `+N more`. The stacked form keeps the seat and claim first, counts wrapped between items next, then `Books:`, `Hubs:`, and the clock last if rows allow. If fewer terminal rows are available, show only the first lines that fit in that order. Width is `--width`, else positive whole `stdout.columns`, else the single `DEFAULT_DASHBOARD_WIDTH` constant (80 cells), with a floor of 30. Every width check counts terminal cells: combining marks zero, East Asian wide/fullwidth characters two, other characters one, ANSI colour codes zero; `●` and `·` each count one.

Catppuccin Mocha roles: labels dim `#6c7086`, names plain `#cdd6f4`, zero counts `#a6adc8`, attention peach `#fab387` and bold, held dot green `#a6e3a1`. Colour is `none` when stdout is not a terminal or `NO_COLOR` is nonempty; otherwise `COLORTERM=truecolor` or `24bit` selects `truecolor`, with `256` as the fallback. One xterm-256 table supplies the nearest indices. Colour is chosen once per run, every coloured run is reset, and every coloured line ends in a reset; labels from the overview have control characters stripped.

The clock is the last successful read's local `<h:mm AM/PM>`, left-padded to exactly eight cells (` 4:21 PM`). A failed read never advances it and retains the `unknown since` line until recovery. A changed frame redraws whole. On a terminal, a successful read in a new minute with no other change rewrites only the whole eight-cell clock field, resets colour and keeps the cursor hidden; it clears no other line. A stdout resize redraws from the last good overview at the new width without reading the Desk again. Terminal frames have no trailing newline, keeping a pane exactly as tall as its frame from scrolling; exit restores the cursor and moves below the frame. Non-terminal frames retain the `---` separator and final newline, and a minute change alone prints nothing.

The command is read-only: no model call, no Book or Project page opened and nothing written. It polls every five seconds by default (configurable from two to sixty seconds) and redraws when its frame or checkpoint record changes. Ctrl+C exits cleanly. Orca owns its bottom usage strip; the pane does not repeat it. `--json` on a one-shot read keeps every underlying Desk overview key unchanged and adds `checkpoint: { conversation, record_at, save, closeout }`, or `checkpoint: null`. The exact `this_seat.seat_id` and `this_seat.session_id` name the file; there is no newest-file fallback. `record_at` is the record file's modification time in ISO form, read from the same open file handle as its bytes. No session or no file means null without an error; malformed records mean null plus `checkpoint_error`, the refusal's first line. The reader uses `validateCheckpoint`, including the optional finite-number-or-null `closedOutAt`, and takes no lock or claim.

The shared `checkpointView(state, now)` projection supplies save words `saved <age>`, `unsaved`, `asked`, `gaps` or `waits`, and closeout words `none`, `asked`, `done <age>`, `gaps`, `waits` or `stale`. Save age uses `savedAt`; clean closeout writes its own optional `closedOutAt`, retained across a later save and cleared when closeout returns to `none`. An old record without that field shows `done` without an age. There is no turn count. Line 4 is Option A: `Save   saved 12 min    Closeout  done 2 h`. Labels use the dim label role; saved and done use the name colour; unsaved, gaps, waits and stale use bold attention. Four-space gaps shrink to two before stacking `Save: …` and `Closeout: …`; the existing stacked layout also stacks these fields, before its `as of` line. No record means no line. A malformed checkpoint in watch omits the save/closeout line and displays the decoder's first-line refusal with an unknown-since warning; the next valid read clears it. The pure frame opens nothing; one-shot and watch callers supply the view, with watch reading it each poll. The redraw key includes the view and its record timestamp, so another save with the same displayed words still redraws. The three existing strip lines retain their text.

Every TTY frame, clock update and unchanged poll ends by parking the cursor at row 1, column 1 and sending DECTCEM hide again. This restores the requested state within one poll if a terminal resets it on focus or resize. The exit write still restores the cursor below the frame. c53 proves the emitted protocol with a fake TTY; physical cursor visibility in Orca and Windows Terminal remains a human check, using `D:/dev/c53-session/cursor-probe.mjs`. The physical cause is unverified.

`deskpost seat settings <seat> --pane on|off|unset` sets the automatic-opening preference for the next launch. It is a cosmetic, reversible write with no preflight or plan id. Its own `.claude/seats/<seat>/pane.json` holds only `{"pane":"on"}` or `{"pane":"off"}`; `unset` removes that file. It leaves inbound's `settings.json` intact in either write order. `seat describe <seat>` reports `pane: on`, `off` or `default (on for Codex, off for Claude)`. An absent preference uses that default; malformed JSON or an unknown value also uses it, with one stderr diagnostic.

The launcher reads `orca terminal list --json` and scopes `Desk: <seat>` to the current terminal's tab and worktree. A matching title keeps the existing pane; otherwise it requests `terminal split --direction horizontal` on the agent's handle, then titles the returned terminal `Desk: <seat>`. The command names this launcher's absolute executable (plus its absolute CLI script when run from source), with explicit seat and workspace. Windows quoting targets the PowerShell route exercised by the fixture. Each Orca call has a ten-second bound; any failure is one stderr line and the agent starts. With no handle or no Orca executable, an enabled pane gives one stdout line: `Desk pane: run deskpost dashboard --watch --seat <seat> --workspace <workspace> in a second terminal.` The workspace is quoted with the same platform rule as the split command. `--pane off` suppresses automatic opening and that instruction. The preference controls startup; Orca retains existing panes. A renamed pane is not recognised by the title check; close an old pane once after upgrading so the next launch uses the new executable. c53 proves this routing with a fake Orca; a fresh-seat visual check must still establish real placement and appearance.
